# 🛍️ Sistema de Recomendação de Produtos Baseado em Grafos

## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema de recomendação de produtos utilizando a estrutura de dados **grafos** para representar conexões e relacionamentos entre produtos.

A proposta é explorar como essas relações podem ser utilizadas para identificar produtos relacionados e gerar recomendações relevantes, contribuindo para uma experiência de compra mais personalizada.

O projeto também permite aplicar conceitos fundamentais de estruturas de dados, algoritmos e desenvolvimento de software.

## 🎯 Objetivos

- Compreender a aplicação de grafos em sistemas de recomendação.
- Representar produtos e seus relacionamentos por meio de uma estrutura conectada.
- Explorar formas de identificar produtos relacionados.
- Aplicar conceitos de algoritmos e estruturas de dados.
- Desenvolver uma solução prática para um problema comum no comércio eletrônico.

## 🧠 Conceito utilizado

### Grafos

Um grafo é uma estrutura de dados composta por **vértices (nós)** e **arestas (conexões)**.

Neste projeto, os vértices podem representar produtos, enquanto as arestas representam relações entre eles.

Exemplo conceitual:

```text
        Notebook
        /      \
   Mouse       Teclado
       \        /
        Acessórios
```

A partir dessas conexões, um sistema pode explorar relações entre produtos para identificar possíveis recomendações.
